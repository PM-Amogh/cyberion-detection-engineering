# Cyberion — Detection Engineering & Threat Hunting

## Overview
A detection engineering and threat hunting project focused on analyzing security telemetry, developing and testing Sigma detection rules, identifying detection coverage gaps, investigating suspicious activity, and documenting incident response procedures.

## Objectives
- Analyze security telemetry from multiple log sources.
- Develop and validate Sigma detection rules.
- Map detections to MITRE ATT&CK.
- Conduct hypothesis-driven threat hunts.
- Investigate suspicious events and construct incident timelines.
- Research and operationalize indicators of compromise (IOCs).
- Tune detection logic to reduce false positives.
- Develop incident response playbooks.

## Project Scope
This project uses publicly available datasets and controlled lab telemetry. Findings will be based on documented evidence and reproducible analysis.

## Project Structure
- `datasets/` — Dataset sources and selection notes.
- `data_dictionary/` — Log fields and their meanings.
- `sigma_rules/` — Detection rules.
- `rule_testing/` — Testing data and validation evidence.
- `threat_hunting/` — Hunting hypotheses and findings.
- `incident_investigations/` — Investigation reports and timelines.
- `attack_coverage/` — MITRE ATT&CK coverage assessment.
- `threat_intelligence/` — IOC research and analysis.
- `playbooks/` — Incident response procedures.
- `rule_tuning/` — Detection tuning records.
- `reports/` — Project reporting.
- `presentation/` — Final presentation materials.

## Methodology
Learn → Analyze → Detect → Test → Investigate → Tune → Document
